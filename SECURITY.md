# Security Policy

## Supported versions

Only the latest release is supported.

## Reporting a vulnerability

Report it through [GitHub private vulnerability reporting](https://github.com/axelhamil/nixos-starter/security/advisories/new). Do not open a public issue.

Expect a first answer within a week (best effort, solo maintainer). Confirmed issues are fixed in priority.

## Scope

The starter's modules, scripts and CI workflows. Vulnerabilities in packages or NixOS modules from nixpkgs belong upstream, in [nixpkgs](https://github.com/NixOS/nixpkgs/security).
